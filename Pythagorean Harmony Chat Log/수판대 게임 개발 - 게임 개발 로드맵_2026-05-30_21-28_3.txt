- MinOperand = FMath::Clamp(Rank, 1, 9000)
- MaxOperand = FMath::Clamp(5 + Rank * 3, MinOperand + 1, 10000)

3. For Add equations:
- answer x should be between MinAnswer and MaxAnswer
- a should be between MinOperand and MaxOperand
- b = x + a

4. For Subtract equations:
- answer x should be between MinAnswer and MaxAnswer
- a should be between MinOperand and MaxOperand
- b = x - a
- Negative b is allowed for now, but the correct answer should remain non-negative.

5. For Multiply equations:
- answer x should be between MinAnswer and MaxAnswer
- a should be between max(2, MinOperand) and MaxOperand
- b = a * x
- Prevent int overflow safely.

6. For Divide equations:
- result should be between MinAnswer and MaxAnswer
- a should be between max(2, MinOperand) and MaxOperand
- correct answer x = result * a
- Display: x / a = result
- Prevent int overflow safely.

- x + 5 = 10
- answer 5
