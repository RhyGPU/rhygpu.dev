Goal:
Support prototype addition, subtraction, multiplication, and division operations that apply to both sides of the current polynomial equation.

Requirements:

1. Add enum EPrototypeOperationType if useful:
- Add
- Subtract
- Multiply
- Divide

2. In UEnemyEquationComponent, add BlueprintCallable function:
- bool ApplyOperationToBothSides(EPrototypeOperationType OperationType, int32 Value)

3. Keep existing ApplySubtractionOperation(int32 Value), but make it call ApplyOperationToBothSides(Subtract, Value) internally.

4. Operation behavior:

Addition:
- If Value == 0, return false for now.
- Add Value to the polynomial constant term.
- Add Value to RightValue.
- Normalize terms.
- Refresh display.
- Return true.

Subtraction:
- If Value == 0, return false for now.
- Subtract Value from the polynomial constant term.
- Subtract Value from RightValue.
- Normalize terms.
- Refresh display.
- Return true.

Multiplication:
- If Value == 0, return false for now.
- Multiply every left-side coefficient by Value.
- Multiply RightValue by Value.
- Use int64 during calculation.
- If any result would overflow int32, return false and leave the equation unchanged.
- Normalize terms.
- Refresh display.
- Return true.

Division:
- If Value == 0, return false.
- Only succeed if every left-side coefficient and RightValue divides cleanly by Value.
- If not cleanly divisible, return false and leave the equation unchanged.
- Divide every left-side coefficient by Value.
- Divide RightValue by Value.
- Normalize terms.
- Refresh display.
- Return true.

5. Add helper functions if useful:
- bool CanMultiplyEquationBy(int32 Value) const
- bool CanDivideEquationByCleanly(int32 Value) const

- bool ApplyAdditionToEnemy(int32 Value)
- bool ApplySubtractionToEnemy(int32 Value)

- bool ApplyOperationToEnemy(EPrototypeOperationType OperationType, int32 Value)

Each should call the equation component and refresh display only when successful.

- R = apply multiplication to nearest equation enemy using current input
- F = apply division to nearest equation enemy using current input
- X behavior should remain answer submission

"No input."

"No equation enemy in range."

"Applied Multiplication: xN"
