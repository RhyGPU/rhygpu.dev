Likely files:
- EquationTypes.h
- EnemyEquationComponent.h
- EnemyEquationComponent.cpp

Do not modify player input, character input binding, enemy actor display logic, UI, weapons, inventory, or AI unless required for compilation.

Goal:
Wrong answers should increase Rank and generate a new equation procedurally instead of selecting from only three hardcoded equations.

Requirements:

1. Keep EPrototypeEquationType:
- Direct
- Add
- Subtract
- Multiply
- Divide

2. Keep FEquationDefinition, but update it if useful.

3. In UEnemyEquationComponent, add procedural generation functions:
- GenerateEquationForRank(int32 NewRank)
- GenerateDirectEquation(int32 NewRank)
- GenerateAddEquation(int32 NewRank)
- GenerateSubtractEquation(int32 NewRank)
- GenerateMultiplyEquation(int32 NewRank)
- GenerateDivideEquation(int32 NewRank)

4. Evolution behavior:
- On wrong answer, increase Rank by 1.
- Generate a new equation for the new Rank.
- Do not cap at Rank 3 anymore.
- For safety, cap Rank at 999 for now.

5. Starting behavior:
- Begin with a deterministic beginner Goblin equation by default:
  x + 5 = 10
  answer 5
  rank 1

6. After the first wrong answer:
- Generate procedural equations based on Rank.

7. Difficulty scaling:
Use Rank to increase number ranges.

Suggested ranges:
- MaxAnswer = 10 + Rank * 5
- MaxOperand = 5 + Rank * 3

Clamp both to reasonable values to avoid int overflow:
- MaxAnswer <= 100000
- MaxOperand <= 10000

8. Equation generation rules:

Direct:
- Pick answer x
- Display: x = answer
- CorrectAnswer = answer

Add:
- Pick answer x
- Pick a
- b = x + a
- Display: x + a = b
- CorrectAnswer = x

Subtract:
- Pick answer x
- Pick a
- b = x - a
- Display: x - a = b
- CorrectAnswer = x

Multiply:
- Pick answer x
- Pick a from 2 to MaxOperand
- b = a * x
- Display: a x = b
- CorrectAnswer = x

Divide:
- Pick answer x
- Pick a from 2 to MaxOperand
- b = x / a style equations should stay integer-friendly.
Use:
  result = random positive integer
  x = result * a
  Display: x / a = result
  CorrectAnswer = x

9. Equation type selection:
For now, choose based on Rank:
- Rank 1 to 2: Add only
- Rank 3 to 4: Add or Subtract
- Rank 5 to 6: Add, Subtract, or Multiply
- Rank 7 and above: Add, Subtract, Multiply, or Divide

Do not use Direct in random evolution yet except if explicitly called.

10. Add BlueprintCallable function:
- RegenerateEquation()

This should generate a new equation for the current rank.

11. Add BlueprintCallable function:
- SetRankAndGenerateEquation(int32 NewRank)

This should set rank and generate an equation for that rank.

12. Add useful UE_LOG messages when an equation is generated:
- Rank
- DisplayText
- CorrectAnswer

13. Keep beginner-friendly comments.

14. Preserve existing public functions:
- GetDisplayText()
- GetCorrectAnswer()
- GetRank()
- IsAnswerCorrect()
- SubmitAnswer()

15. Update SubmitAnswer:
- Correct answer returns true.
- Wrong answer evolves procedurally and returns false.

Before finalizing, explain:
1. Which files were changed
2. How procedural generation works
3. How Rank affects difficulty
4. How to test in Play mode
