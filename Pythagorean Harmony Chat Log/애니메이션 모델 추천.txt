## 3. 모델은 무료 에셋 먼저, AI 생성은 나중

무료 모델 소스 우선순위:

1. **Fab 무료/limited-time free assets** 
 Unreal에 바로 맞는 에셋이 많아서 가장 편함. Fab은 Epic 쪽 실시간/game-ready 에셋 마켓플레이스임. ([Fab.com](https://www.fab.com/?utm_source=chatgpt.com))

2. **Quaternius** 
 Low poly 3D 모델이 많고 CC0라서 프로토타입에 안전하게 쓰기 좋음. ([quaternius.com](https://quaternius.com/?utm_source=chatgpt.com))

3. **Kenney** 
 수천 개 무료 게임 에셋 제공. 카툰/low-poly 느낌에 맞음. ([kenney.nl](https://kenney.nl/?utm_source=chatgpt.com))

4. **Poly Haven** 
 CC0 3D 모델, HDRI, texture 쪽에 좋음. 몬스터보다는 바닥, 돌, 나무, 환경 props, texture에 적합함. ([Poly Haven](https://polyhaven.com/?utm_source=chatgpt.com))

AI 3D 생성은 **Meshy, Tripo, Rodin/Hyper3D** 정도를 실험용으로 보면 됨. Meshy는 무료 플랜이 100 monthly credits라고 명시되어 있고, Tripo는 text/image to 3D와 auto rigging/low-poly 기능을 내세우고 있음. Rodin/Hyper3D도 text/image 기반 3D asset generation을 제공함. 단, AI 모델은 바로 게임용으로 완벽하지 않은 경우가 많아서 retopology, rigging, collision, material 정리가 필요함. ([Meshy AI - The #1 AI 3D Model Generator](https://www.meshy.ai/?utm_source=chatgpt.com))

이유는 간단함. 이미 네 전투 시스템이 UE 기반이고, 애니메이션 Retargeting, Montage, Notify, Root Motion, IK Retargeter를 다루기 쉬움. 지금 커스텀 주인공 모델 만들면 시간 빨림.

애니메이션은 우선 **Epic Animation Starter Pack**부터 쓰면 됨. 이 팩은 Epic Skeleton용 62개 애니메이션을 제공하고, 프로토타입/모드/게임 학습용으로 쓰기 좋다고 설명되어 있음. ([Unreal Engine](https://www.unrealengine.com/ko/blog/new-release-animation-starter-pack-and-2d-platformer-pack?utm_source=chatgpt.com))

추가로 **Mixamo**를 쓰면 기본 humanoid idle, walk, run, dodge, hit reaction, death, attack류를 빠르게 채울 수 있음. Adobe 공식 FAQ 기준 Mixamo는 추가 구매/구독 없이 무료이고, 캐릭터와 애니메이션을 개인/상업/비영리 프로젝트에 royalty-free로 사용할 수 있다고 설명되어 있음. 단, 최종 배포 전에는 Adobe/Mixamo 현재 약관을 다시 확인해야 함. ([Adobe 도움말 센터](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html?utm_source=chatgpt.com))

### B. 적 모델

**Quaternius Ultimate Monsters**가 지금 네 게임에 제일 잘 맞음.

이유: 네 GDD의 아트 방향은 “카툰 렌더링, 애니메이션풍 판타지, 과장된 실루엣, 읽기 쉬운 수식 UI”임. Quaternius Ultimate Monsters는 50개 fully animated monsters를 포함하고, FBX/OBJ/Blend 형식이며, 개인/상업 프로젝트에 무료 사용 가능하다고 적혀 있음. 슬라임, 고블린 대체, 오크 대체, 괴물형 적 placeholder 만들기에 매우 좋음. ([quaternius.com](https://quaternius.com/packs/ultimatemonsters.html?utm_source=chatgpt.com))

**Kenney**도 좋음. Kenney는 게임 에셋들이 CC0/public domain이고 상업 프로젝트에도 사용 가능하다고 설명함. 다만 캐릭터 전투 애니메이션보다는 UI, 아이콘, 간단한 3D 소품, 환경 placeholder 쪽에 더 적합함. ([kenney.nl](https://kenney.nl/?utm_source=chatgpt.com))

**Poly Haven**은 캐릭터보다는 HDRI, 환경, 오브젝트, 텍스처 쪽. 모든 에셋이 CC0라서 라이선스 걱정이 거의 없고, 로그인 없이 다운로드 가능하다고 설명되어 있음. ([Poly Haven](https://polyhaven.com/?utm_source=chatgpt.com))

### C. Fab 무료 에셋

Fab도 봐야 함. Fab에는 무료 에셋 라이브러리가 있고, 일정 주기로 유료 에셋 일부가 제한 기간 무료로 풀림. 다만 Fab은 에셋마다 Creative Commons 또는 Standard License가 다를 수 있으니, 무조건 각 asset page의 license를 확인해야 함. ([Unreal Engine](https://www.unrealengine.com/fabfreecontent?utm_source=chatgpt.com))

**주의:** Fab에서 “와 예쁘다” 하고 스타일 섞으면 게임이 개판 됨. 지금은 한 스타일만 써야 함. 네 게임은 카툰/애니메이션풍이므로, realistic AAA asset은 일단 피하는 게 맞음.

## Kimodo는 언제 쓰나?

Kimodo는 지금 “메인 애니메이션 소스”가 아니라 **나중에 특수 모션 생성용**으로 봐야 함.

좋은 사용처:

- Axiom Execution 특수 처형 모션
- 수식 조율 포즈
- 보스 등장 모션
- 특수 그로기/붕괴 모션
- 일반 라이브러리에 없는 수학적 제스처

안 좋은 사용처:

- 기본 idle
- walk/run
- dodge
- block
- hit reaction
- death
- 일반 공격

이런 기본 모션은 이미 Mixamo, Animation Starter Pack, 무료 몬스터 팩으로 빠르게 해결하는 게 훨씬 효율적임.

## AI mocap 대안

무료/저가로 직접 모션 만들고 싶으면 Kimodo보다 아래가 먼저 현실적임.

**Rokoko Vision / Rokoko Studio** 
Starter 플랜이 무료이고, FBX export가 포함되어 있으며, 15초 미만 video-to-motion과 text-to-motion 기능이 포함되어 있음. 단, 제한이 있으니 짧은 테스트 모션용으로 좋음. ([rokoko.com](https://www.rokoko.com/products/vision?utm_source=chatgpt.com))

**Plask** 
무료 플랜에 하루 15초 motion capture 제한이 있고, FBX/GLB/BVH export를 제공한다고 설명되어 있음. 짧은 모션 테스트에는 좋음. ([Plask Motion](https://plask.ai/pricing?utm_source=chatgpt.com))

**DeepMotion Animate 3D** 
무료 계정은 월 60초 animation 생성이 가능하지만, 공식 가격 페이지 기준 personal, non-commercial use로 제한되어 있음. 그래서 Steam 상업 출시까지 생각하면 라이선스 확인이 필요함. ([deepmotion.com](https://www.deepmotion.com/pricing-animate3d?utm_source=chatgpt.com))

**Cascadeur** 
좋은 animation cleanup/editing 툴이지만, 무료 플랜은 non-commercial이고 FBX/DAE export가 막혀 있음. 즉 지금 프로토타입 학습용으로는 좋지만, UE에 최종 export하려면 유료가 필요할 수 있음. ([cascadeur.com](https://cascadeur.com/download?utm_source=chatgpt.com))

# 1. 네가 원하는 스타일에 진짜 맞는 방향

네 레퍼런스는 **애니 스타일 캐릭터**다.

그래서 **애니 캐릭터는 “AI 완전 자동”보다 “애니용 베이스 + AI 보조”가 더 잘 맞음**.

# 2. 가장 추천하는 파이프라인, 애니 캐릭터용

## 루트 A, 제일 추천
### **VRoid Studio → Blender → Mixamo / Rokoko / DeepMotion → Unreal**

이게 왜 좋냐면,

- **VRoid Studio는 무료 다운로드 가능**하고, 캐릭터를 직접 만들기 쉬움.
- VRoid는 “original characters”를 쉽게 만들 수 있다고 안내하고 있음.
- 네가 **직접 만든 텍스처와 헤어 메시는 권리가 네게 있음**. 다만 기본 프리셋 메쉬와 의상 메쉬 같은 건 pixiv 제공 콘텐츠라서 약관은 읽어야 함.

### 이 루트가 네 스타일에 맞는 이유
- 애니 얼굴, 머리카락, 비율 잡기가 쉬움
- “나만의 캐릭터” 만들기 좋음
- 나중에 Blender에서 갑옷, 무기, 디테일 덧붙이기 좋음
- 언리얼용 humanoid 파이프라인으로 연결이 편함

### 단점
- 완전 자동 AI는 아님
- 옷/갑옷을 네가 어느 정도 손봐야 함

### 내 판단
**네가 보여준 스타일과 가장 잘 맞는 건 사실 이쪽임.** 
사진 1장 기반 AI 3D보다 결과가 더 “애니답게” 나올 가능성이 높음.

# 3. 사진으로 바로 3D 모델 뽑고 싶으면

## 루트 B, 로컬 우선
### **Hunyuan3D 2.0**

이건 꽤 괜찮은 후보다.

공식 GitHub 기준으로 Hunyuan3D 2.0은 **Windows, macOS, Linux**를 지원하고, **Code, Gradio App, API Server, Blender Addon, Official Site** 방식으로 사용할 수 있다고 적혀 있음. 
또한 이미지로부터 메시를 만들고, 결과 메시를 **glb/obj 같은 포맷으로 저장**할 수 있다고 설명함.

### 왜 추천하냐
- 오픈소스 계열
- 이미지 → 3D에 맞음
- Blender addon까지 있어서 연결이 괜찮음
- 네가 “내 컴퓨터에서 돌리고 싶다”는 요구랑 가장 가까움

### 6800 XT에서 가능성?
AMD 공식 문서상 **RX 6800 XT는 Windows용 HIP SDK 지원 GPU 목록에 들어가 있음**. 
즉, **AMD 6800 XT로 로컬 AI 작업 시도 자체는 가능성 있음**. 다만 현실적으로는 많은 오픈소스 3D AI 툴이 CUDA 중심으로 돌아가서, **NVIDIA보다 설치가 더 귀찮고 시행착오가 많을 가능성**이 큼. 이건 내 실무적 판단임.

### 솔직한 결론
로컬로 하나만 먼저 찍어볼 거면 
**Hunyuan3D 2.0이 1순위**다.

- 이미지 → 3D 테스트용으로 좋음
- 웹이라 세팅 귀찮음 적음

### 단점
- 무료 제한 꽤 있음
- 스타일 통제는 Tripo와 비슷하게 “운 + 후편집” 필요

**Tripo와 같이 시험해볼 2순위 웹 툴.**
