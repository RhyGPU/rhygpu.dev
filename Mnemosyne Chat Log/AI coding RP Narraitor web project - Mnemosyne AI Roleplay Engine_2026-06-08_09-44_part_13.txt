4. High-Score Gate

High scores must be possible, but difficult to earn.

A single normal positive event should not instantly create extreme trust, intimacy, or loyalty. High scores require one or more of:

high stakes
personal cost
consistent repetition
direct vulnerability
risk of loss
protection under pressure
betrayal opportunity refused
repair after serious harm
Bias Delta Caps

Per event maximum change:

minor event:
  durable bias delta cap = 2 to 5

moderate event:
  durable bias delta cap = 5 to 10

major event:
  durable bias delta cap = 10 to 18

critical turning point:
  durable bias delta cap = 18 to 30

High trustable bias requires:

trustable_bias above 60:
  requires either repeated reliability or one high-cost/high-stakes loyalty event

trustable_bias above 80:
  requires multiple reinforced events or a major critical event

trustable_bias above 90:
  requires long-term pattern or extreme sacrifice/loyalty

trust >= moderate
comfort >= moderate

boundary_pressure not extreme

5. Reappraisal System

The engine must allow the character to realize:

I may have judged this person wrong.
My first impression was incomplete.
This person is not what I thought.

This is not the same as normal score change. It is a belief revision event.

Reappraisal Debt

For each durable bias, track contradiction evidence:

disconfirmation_debt[bias]

When an event strongly contradicts an established bias:

disconfirmation_debt += event_strength * contradiction_strength

Example:

If untrustworthy_bias is high,
but target acts honestly under pressure:
  disconfirmation_debt[untrustworthy_bias] increases.
Reappraisal Trigger

Enter reappraisal mode if any condition is true:

disconfirmation_debt exceeds threshold
critical event directly contradicts current bias
three or more medium contradiction events occur
trusted third-party correction appears
user/OOC correction marks prior interpretation wrong
target performs costly action inconsistent with old bias

Recommended threshold:

threshold = 8 + 0.12 * bias_strength + 0.08 * evidence_count

This means stronger, older biases are harder to overturn.

Reappraisal Effects

When triggered:

- reduce resistance temporarily
- allow a larger corrective update
- write a reappraisal memory
- mark old impression as "under review"
- generate narrator surface text saying the character is reconsidering

Example internal result:

first_impression_status: under_review
reappraisal_reason: "He had the chance to betray her and did not."
affected_biases:
  - untrustworthy_bias down
  - trustable_bias up
