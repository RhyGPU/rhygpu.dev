AGPL-3.0-or-later	Your code is licensed under AGPL version 3, and also any future version of the AGPL that the FSF might publish. Users can choose to follow the terms of AGPL v3 or any later version.
Think of it as: "I trust the FSF to keep future AGPL versions aligned with the spirit of this license, so I'll let my code automatically upgrade."

Why This Matters
If you choose AGPL-3.0-only:

You have exact control. If AGPL v4 includes a clause you dislike, your code stays under v3.

But it creates fragmentation. Some projects use v3-only, others adopt v4. Code from v3-only and v4 projects might be incompatible to combine, because you'd have to satisfy both licenses. This is a well-known openâ€‘source licensing headache.

If you choose AGPL-3.0-or-later:

Your code remains compatible with any future AGPL version.

You're trusting the FSF's stewardship. Historically, the FSF has been very careful about preserving user freedoms when updating the GPL/AGPL.

Most major GNU projects use "or-later" for exactly this reason (Linux is a notable counterâ€‘exampleâ€”GPLv2-onlyâ€”which has caused decades of compatibility grief).

How It's Indicated
In source files, you'll often see:

text
SPDX-License-Identifier: AGPL-3.0-or-later
In Cargo.toml (Rust) and package.json (Node), the string "AGPL-3.0-or-later" is used exactly as you've done.

This is standardized by the SPDX project, so tools and platforms (GitHub, npm, crates.io) recognize it correctly.

Is It Still Strong Copyleft?
Yes, absolutely. Both variants are identical today. They require:

Anyone who distributes your code (or modified versions) must release the source under the same license.

Anyone who runs a modified version as a network service must release their changes.

The "or-later" clause simply says that if the FSF releases AGPL v4, users can then choose to follow AGPL v4's terms instead of v3's. The FSF has a track record of making future versions more protective, not less.

fn render_visible_response(
    soul: &Soul,
    user_text: &str,
    mode: NarrativeMode,
    template: MockTemplate,
    relationship_hint: &'static str,
) -> String {
    let mode_line = match mode {
        NarrativeMode::Reader => template.reader_line,
        NarrativeMode::Realistic => template.realistic_line,
        NarrativeMode::God => template.god_line,
    };
    let answer = if user_text.ends_with('?') {
        "I do not know the whole answer yet. But I can tell which part of it scares me."
    } else if user_text.is_empty() {
        "Say that again, slower."
    } else {
        "I heard you. That matters more than I expected."
    };

    match mode {
        NarrativeMode::God => format!(
            "[GM] {mode_line}\n\n{} steadies in the scene. Relationship read: {relationship_hint}. \"{answer}\"",
            soul.character_name
        ),
        NarrativeMode::Realistic => format!(
            "{mode_line}\n\n{} answers after a controlled breath. \"{answer}\"",
            soul.character_name
        ),
        NarrativeMode::Reader => format!(
            "{mode_line}\n\n{}'s voice stays low. \"{answer}\"",
            soul.character_name
        ),
    }
}

fn render_memory(
    soul: &Soul,
    user_text: &str,
    template: MockTemplate,
    context_hint: &'static str,
) -> String {
    format!(
        "{} for {}. User turn: {}. Context cue: {}.",
        template.memory_frame, soul.character_name, user_text, context_hint
    )
}

fn render_world_event(user_text: &str, template: MockTemplate) -> String {
    format!("{}: {}", template.world_frame, user_text)
}

fn relationship_hint(soul: &Soul) -> &'static str {
    let Some(relationship) = soul.relationships.get("user") else {
        return "unestablished";
    };
    if relationship.trust >= 45.0 {
        "warming trust"
    } else if relationship.fear >= 40.0 {
        "guarded fear"
    } else {
        "fragile neutrality"
    }
}

fn context_hint(context: &str) -> &'static str {
    if context.contains("[RECENT CHAT]") {
        "recent chat is available"
    } else {
        "fresh scene context"
    }
}
