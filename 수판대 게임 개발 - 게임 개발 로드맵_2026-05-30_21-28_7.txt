- F1/F2/F3/F4/F5 selects a prototype weapon mode.

- EquationActionArmed

- If there is a valid current input and a nearest enemy is found, use the selected prototype weapon once.
- After the attempt, always:
  - Clear player input
  - Return action state to NormalCombat
  - Print "Returned to normal attack."
- The selected weapon should remain the same.

4. If there is no input:
- Show "No input."
- Return to NormalCombat.

5. If there is no enemy in range:
- Show "No equation enemy in range."
- Clear input if there was input.
- Return to NormalCombat.

- C already clears input.
- Extend C so it also cancels equation action preparation and returns to NormalCombat.

- Clear input
- Return to NormalCombat
- Print "Returned to normal attack."

- "Using Weapon: Addition"

- "Using Weapon: Multiplication"

- "Using Weapon: X"
Then result message.
Then "Returned to normal attack."

- Digit input works.
- Backspace works.
- C clears/cancels.
- F1-F5 weapon selection works.
- LMB uses selected weapon once.
